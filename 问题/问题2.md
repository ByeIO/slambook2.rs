## 问题
```rs
// ::from_fn(...) Creates a matrix filled with the values returned by the given closure of type FnMut(usize, usize) -> T. This closure is called exactly once per matrix component and is given as parameter each matrix component's 0-based indices.
let dm4 = Matrix3::from_fn(3, 3, |r, c| if r == c { 1.0 } else { 0.0 });
rand::random()
```
参照如上代码,修改`let matrix_33 = Matrix::from_fn();`以产生一个全是整数随机数的方阵.

### 回答
为了创建一个全是整数随机数的3x3方阵，你需要使用`rand`库来生成随机数。以下是修改后的代码：
```rust
extern crate rand; // 确保在Cargo.toml中添加了rand依赖
use rand::Rng; // 引入Rng trait以使用随机数生成功能
// 假设Matrix是一个已经定义好的类型，这里使用Matrix3作为示例
let matrix_33 = Matrix3::from_fn(3, 3, |_, _| rand::random::<i32>());
```
在这段代码中，`rand::random::<i32>()`会生成一个类型为`i32`的随机整数。`Matrix3::from_fn`函数会为3x3矩阵的每个元素调用这个闭包，从而填充整个矩阵。注意，这里假设`Matrix3`类型已经定义好了，并且能够使用`from_fn`方法。如果你的矩阵类型不同，你可能需要相应地调整代码。

## 问题
```rs
rand::random::<i32>()
```
将如上代码改为lambda表达式;

```rs
|_,_| rand::random::<i32>()
```
closures表达式中将i32结果再转为f64;

### 回答
在Rust语言中，可以使用闭包（closures）来创建lambda表达式。下面是如何将`rand::random::<i32>()`函数调用改写为一个lambda表达式的示例：
```rust
let random_i32 = || rand::random::<i32>();
```
在这个lambda表达式中，`||`表示这是一个没有参数的闭包，`rand::random::<i32>()`是闭包体，它会调用`rand::random`函数并指定类型为`i32`。通过`random_i32`这个变量，你可以多次调用这个lambda表达式来生成随机整数。

在Rust中，您可以使用闭包将`i32`结果转换为`f64`。下面是如何修改闭包以完成这个转换：
```rust
let random_i32_to_f64 = |_, _| rand::random::<i32>() as f64;
```
在这个闭包中，`|_, _|`表示闭包接受两个参数，但是这两个参数并没有被使用（通常用下划线`_`表示未使用的参数）。闭包体中`rand::random::<i32>()`生成一个随机`i32`整数，然后通过`as`关键字将其转换为`f64`浮点数。

在Rust中使用nalgebra库来求解矩阵的特征值和特征向量，您可以使用`SymmetricEigen`结构体，它专门用于对称矩阵的特征值和特征向量的计算。以下是一个求解对称矩阵特征值和特征向量的示例代码：
```rust
use nalgebra::{Matrix3, DMatrix, SymmetricEigen};
fn main() {
    // 创建一个对称矩阵
    let mat = Matrix3::new(2.0, -1.0, 0.0,
                           -1.0, 2.0, -1.0,
                           0.0, -1.0, 2.0);
    // 计算对称矩阵的特征值和特征向量
    let eigen = mat.symmetric_eigen();
    // 获取特征值和特征向量
    let eigenvalues = eigen.eigenvalues;
    let eigenvectors = eigen.eigenvectors;
    // 输出特征值
    println!("Eigenvalues:");
    for ev in &eigenvalues {
        println!("{}", ev);
    }
    // 输出特征向量
    println!("Eigenvectors:");
    for col in 0..eigenvectors.ncols() {
        println!("Eigenvector {}: {:?}", col + 1, eigenvectors.column(col));
    }
}
```
在这个例子中，我们首先创建了一个3x3的对称矩阵`mat`。然后，我们使用`.symmetric_eigen()`方法来计算这个矩阵的特征值和特征向量。计算完成后，我们通过`eigen.eigenvalues`和`eigen.eigenvectors`来分别获取特征值和特征向量，并将它们打印出来。
