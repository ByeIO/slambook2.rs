// 自定义高斯消元法函数,任意维度
fn gaussian_elimination(a: &DMatrix<f64>, b: &DVector<f64>) -> DVector<f64> {
    let n = a.nrows(); // 矩阵的行数（即方程个数）
    // 将 A 和 b 合并为增广矩阵 [A | b]
    let mut augmented = DMatrix::from_element(n, n + 1, 0.0);
    for i in 0..n {
        for j in 0..n {
            augmented[(i, j)] = a[(i, j)];
        }
        augmented[(i, n)] = b[i];
    }
    // 消元阶段：将矩阵 A 转化为上三角矩阵
    for k in 0..n {
        // 1. 选主元：确保当前对角线元素非零
        for i in k + 1..n {
            if augmented[(k, k)] == 0.0 {
                eprintln!("Zero pivot encountered. Matrix is singular!");
                exit(1);
            }
            // 2. 消去第 k 列的第 i 行元素
            let factor = augmented[(i, k)] / augmented[(k, k)];
            for j in k..=n {
                augmented[(i, j)] -= factor * augmented[(k, j)];
            }
        }
    }
    // 回代阶段：从最后一行开始，求解未知数
    let mut x = DVector::from_element(n, 0.0);
    for i in (0..n).rev() {
        x[i] = augmented[(i, n)];
        for j in i + 1..n {
            x[i] -= augmented[(i, j)] * x[j];
        }
        x[i] /= augmented[(i, i)];
    }
    x // 返回值
}

## 问题分析
你编写的 Rust 程序在运行时遇到了 `capacity overflow` 错误。这个错误通常表示在尝试分配内存时，请求的容量超出了允许的最大值。在你的代码中，这个问题可能出现在矩阵操作或向量生成的地方。
## 错误定位
从错误堆栈来看，问题出现在 `nalgebra` 库的矩阵构造函数中，特别是在 `from_iterator` 方法调用时。这表明在创建 `DMatrix` 或 `DVector` 时可能存在不合理的内存分配请求。
## 可能的原因
1. **矩阵大小问题**：虽然你的矩阵大小是 3x3，但在转换为 `DMatrix` 时可能出现了问题。
2. **迭代器问题**：使用 `from_iterator` 方法时，迭代器可能产生了多于预期数量的元素。
## 解决方案
### 1. 检查矩阵转换
你在将 `Matrix3` 转换为 `DMatrix` 时使用了 `from_fn` 方法。这个方法本身没有问题，但确保传入的行数和列数是正确的。
### 2. 检查向量生成
你在生成随机向量 `b` 时使用了 `from_iterator` 方法。确保迭代器生成的元素数量正确。
### 3. 调整代码
尝试简化矩阵和向量的生成方式，避免使用复杂的迭代器操作。

LLT分解（也称为Cholesky分解）是用于将一个正定矩阵分解为一个下三角矩阵和其转置的乘积的算法。在Rust中，我们可以使用类似的方式来实现LLT分解函数。以下是一个示例实现：
```rs
use nalgebra::{Matrix, DimMin, DefaultAllocator, Allocator, DimMinimum};
///	LLT decomposition of a matrix.
pub struct LLT<T, R, C>
where
    R: DimMin<C>,
    DefaultAllocator: Allocator<R, C> + Allocator<R> + Allocator<DimMinimum<R, C>>,
{
    l: Matrix<T, R, DimMinimum<R, C>>,
}
impl<T, R, C> LLT<T, R, C>
where
    T: Copy + std::ops::Mul<Output = T> + std::ops::Add<Output = T> + std::ops::Sub<Output = T> + std::ops::Div<Output = T> + From<f64>,
    R: DimMin<C>,
    DefaultAllocator: Allocator<R, C> + Allocator<R> + Allocator<DimMinimum<R, C>>,
{
    /// Creates a new LLT decomposition from the given matrix.
    pub fn new(mut matrix: Matrix<T, R, C>) -> Self {
        let n = matrix.nrows();
        let mut l = Matrix::zeros(n, n);
        for i in 0..n {
            for j in 0..=i {
                let mut sum = T::from(0.0);
                for k in 0..j {
                    sum = sum + l[(i, k)] * l[(j, k)];
                }
                if i == j {
                    l[(i, i)] = (matrix[(i, i)] - sum).sqrt();
                } else {
                    l[(i, j)] = (matrix[(i, j)] - sum) / l[(j, j)];
                }
            }
        }
        LLT { l }
    }
    /// Returns the lower triangular matrix L.
    pub fn l(&self) -> &Matrix<T, R, DimMinimum<R, C>> {
        &self.l
    }
}
/// Computes the LLT decomposition of this matrix.
pub fn llt<T, R, C>(matrix: Matrix<T, R, C>) -> LLT<T, R, C>
where
    T: Copy + std::ops::Mul<Output = T> + std::ops::Add<Output = T> + std::ops::Sub<Output = T> + std::ops::Div<Output = T> + From<f64>,
    R: DimMin<C>,
    DefaultAllocator: Allocator<R, C> + Allocator<R> + Allocator<DimMinimum<R, C>>,
{
    LLT::new(matrix)
}
```
在这个实现中，我们定义了一个`LLT`结构来存储LLT分解的结果，即下三角矩阵L。`LLT::new`函数接收一个矩阵并计算其LLT分解，存储在`l`矩阵中。`llt`函数是一个公共函数，用于计算矩阵的LLT分解。
请注意，这个实现假设输入矩阵是正定的，并且元素类型`T`支持必要的数学运算。此外，这个实现没有进行任何错误检查，例如检查矩阵是否为正定或是否为方阵。在实际应用中，您可能需要添加这些检查。
另外，这个实现使用了`nalgebra`库，它是一个流行的Rust线性代数库。确保在您的`Cargo.toml`文件中添加了`nalgebra`作为依赖项。
